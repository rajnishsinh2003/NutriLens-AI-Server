About Nutrifexa AI

Nutrifexa AI is a non-invasive dietary monitoring tool developed to automate portion-weight estimation and calorie count computation. Combining state-of-the-art computer vision algorithms, this web dashboard provides clinical-level insights in real-time, assisting users in tracking nutritional intakes and adhering to healthy lifestyle habits.

The Deep Learning Model

Our food classifier is powered by EfficientNet-B3, a convolutional neural network architecture optimized for maximum accuracy and efficiency. EfficientNet uses a compound scaling method that uniformly scales network depth, width, and resolution using a simple yet highly effective compound coefficient.

The network is pre-trained on the ImageNet database (1.2 million images) and then fine-tuned via Transfer Learning on our food classification corpus. This approach allows the network to adapt its edge, texture, and shape detection filters to specific food boundaries with extremely high accuracy.

Architecture Highlights:
  • Depthwise Separable Convolutions to reduce computations
  • Squeeze-and-Excitation blocks to model channel relationships
  • Dropout layer (0.3 rate) to prevent overfitting during transfer training

Calorie Estimation Pipeline

Estimating nutritional values from a 2D image is an underdetermined problem that requires several sequential stages:

1. Object Localization & Cropping A pre-trained YOLOv8-nano model detects the bounding box of the main food item and filters out background noise.
2. Segmenting OpenCV Contours Otsu thresholding and Gaussian blur segment the food boundary, measuring the exact surface area in pixels.
3. Portion Weight Estimation Dynamic cm-per-pixel ratio (calibrated on plate boundaries) is multiplied by density anchors ($\text{g/cm}^3$) to calculate estimated portion weights in grams.
4. Database Nutrition Lookup Nutrifexa matches the predicted food label with a 94-item reference database to calculate scaled calories, carbs, fats, protein, and micro-nutrients.
